# Freebase

> An open source alternative to [Featurebase](https://featurebase.app) — still building.

Feedback boards, changelogs, and roadmaps for your product. Self-hostable, MIT licensed, deployable to Vercel free tier.

---

## What's being built

- **Feedback board** — public voting, comments, status tracking
- **Changelog** — rich text editor, email subscriptions, RSS
- **Roadmap** — kanban view, promote from feedback
- **Embeddable widget** — drop one `<script>` tag, get all three surfaces

## Stack

Next.js 15 · Neon (Postgres) · Supabase Auth · Prisma · Tailwind v4 · Upstash Redis · Resend
